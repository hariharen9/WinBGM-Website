SAFETY IS THE FOUNDATION

Control without
the cliff edge.

System-level tools should never make risky changes feel casual. WinBGM is built around a simple principle: understand first, preserve the original state, and make every supported change reversible.

GOOD TO KNOW

Before you
take control.

A few practical details about what WinBGM is — and what it isn't.

Does WinBGM delete startup entries? +

No. Its documented safety approach avoids deleting files or registry entries. For supported startup changes it uses native state controls, such as StartupApproved bitmasks, service startup-type changes and Task Scheduler toggles.

Can I undo a change? +

WinBGM records original values in its local change history before applying supported modifications. You can restore individual entries, and batch sessions support a one-action restore.

Does it replace Task Manager or Autoruns? +

It is a focused companion for understanding and managing background activity. It combines app-grouped discovery with safeguards, live process context, boot and power diagnostics, snapshots and history.

Can I add my own startup entries? +

Yes. WinBGM lets you create custom startup entries — either an instant Run key or a delayed logon task via Windows Task Scheduler. You can set a boot delay in seconds, run hidden, and optionally request elevation.

Which Windows versions and architectures are supported? +

The project targets Windows 10 and Windows 11, with release binaries listed for x64, ARM64 and 32-bit x86 Windows.

Does WinBGM have an installer now? +

Yes, from v1.1.1 onwards WinBGM ships both a portable .zip and an Inno Setup installer (.exe) that installs to Program Files, adds a Start Menu shortcut, and appears in Add/Remove Programs. Both options are on GitHub Releases.

Does the website download or install anything automatically? +

No. The download button opens the project's GitHub Releases page. You choose the release asset you want to download.

Is any of my data uploaded anywhere? +

No. Snapshots, change history and scan results stay on your PC. WinBGM has no accounts, no sync and no telemetry — reviewing your inventory is entirely local.

Is WinBGM free? +

Yes. WinBGM is open source under the MIT license, and every release build is published for free on GitHub Releases.
